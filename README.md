# ScholMart - School Uniform B2B SaaS Platform

A production-grade SaaS web application for school uniform manufacturers and suppliers.

## Tech Stack
- **Framework**: Next.js 14+ (App Router, TypeScript)
- **Styling**: Tailwind CSS, CSS Design Tokens, Glassmorphism, Responsive UI
- **3D & Visuals**: Three.js, React Three Fiber, @react-three/drei
- **Motion**: Framer Motion, Lenis Smooth Scroll
- **State & Data**: TanStack Query, Zustand, React Hook Form, Zod
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: JWT & RBAC (Supplier Admin, School Rep, Tailor/Production, Staff)

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
